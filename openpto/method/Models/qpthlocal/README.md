# qpthlocal — vendored qpth

Vendored copy of [qpth](https://github.com/locuslab/qpth), the differentiable
batched QP solver by Brandon Amos and J. Zico Kolter (used here by the QPTL
method). It entered this codebase via the upstream Geng et al. benchmark
release, lightly modified (a cvxpy solver backend was added).

qpth is licensed under the Apache License 2.0 — see [LICENSE](LICENSE) in this
directory. Copyright belongs to the qpth authors.

Reference: Amos & Kolter, "OptNet: Differentiable Optimization as a Layer in
Neural Networks", ICML 2017.
